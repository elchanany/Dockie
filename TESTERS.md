# Testers — Dockie closed testing

## Why this matters

Google requires a **closed test with at least 12 opted-in testers for 14 continuous days** before a new personal Play developer account can request production access.

Opted-in means each person must open the opt-in link and accept — merely being listed is not enough.

## Exact opt-in steps (send to each tester)

1. Open the **closed testing opt-in URL** (Play Console → Testing → Closed testing → Testers → copy link).
2. Sign in with the **Google account** that was invited.
3. Tap **Become a tester** / accept.
4. Install **Dockie** from the Play Store link on that page (or search after opt-in).
5. Keep the invitation accepted for the full **14 days** (do not leave the test early).

## What to test (short)

1. Complete onboarding and allow “modify system settings”.
2. Enable Dockie → put phone on a **wireless** charger → confirm screen stays awake.
3. Lift phone → confirm normal timeout returns.
4. Try USB charging → Dockie must **not** activate.
5. Power button must still turn the screen off.
6. Optional: Settings → custom duration wheel; dark theme.
